# Testing page4j

Tests are in `src/test/java` and their fixtures in `src/test/resources`. JUnit 5 runs them all
through the same Gradle task.

## Running Tests

```bash
# Run the complete test suite
./gradlew test

# Run the tests of one package
./gradlew test --tests 'com.maxnth.page4j.formats.*'

# Run a particular test class
./gradlew test --tests '*PageXmlGoldenTest'

# Re-run all tests, even if they are up to date
./gradlew test --rerun-tasks

# Run tests, formatting checks and static analysis, and build the JARs
./gradlew build
```

The HTML test report is generated at `build/reports/tests/test/index.html`.

## Test Suites

| Test                                    | What it checks                                                      |
| --------------------------------------- | ------------------------------------------------------------------- |
| `model.*`                               | Records, `Page` lookups and edits, consistency checks               |
| `model.value.ModelEnumsMatchSchemasTest`| The enums list exactly the values of the bundled schemas            |
| `pagexml.internal.PageXmlReaderTest`, `PageXmlWriterTest` | Reading and writing details per version      |
| `pagexml.PageXmlTest`                   | The facade: streams, paths, errors, XML security, concurrency       |
| `pagexml.RoundTripFidelityTest`         | Same-version round trips of every fixture against a known-differences ratchet |
| `pagexml.PageXmlGoldenTest`             | Conversion of one document to every version against golden files    |
| `convert.PageConverterTest`             | Each rule of the version conversion                                 |
| `formats.*`                             | The ALTO, FineReader, hOCR and METS readers and the ALTO writer     |

## Fixtures

| Folder                | Contents                                                                    |
| --------------------- | --------------------------------------------------------------------------- |
| `coverage/`           | One document per version that uses every element and attribute of its schema, generated by `scripts/generate-coverage-documents.py` |
| `fidelity/`           | Small documents for round-trip edge cases; `fidelity/lenient/` holds invalid ones that must fail to read |
| `fidelity/known-differences.txt` | Round-trip differences the library still produces             |
| `golden/`             | `source.xml` (2024-07-15) converted to every version, with the conversion messages |
| `document.xml`        | A real-world document                                                       |

Every PAGE document under `fidelity/` and `coverage/` is round-tripped automatically,
so a new fixture only has to be put in one of these folders.

`known-differences.txt` is a ratchet: a round-trip difference that is not listed fails the test,
and so does a listed difference that no longer occurs. Remove the line when you fix one.

To regenerate the golden files after an intended change to the writer or the converter, run the
golden test with `PAGE4J_UPDATE_GOLDENS=true` and review the diff:

```bash
PAGE4J_UPDATE_GOLDENS=true ./gradlew test --tests '*PageXmlGoldenTest' --rerun-tasks
```

The bundled schemas are in `src/main/resources/com/maxnth/page4j/pagexml/schemas`. After adding a
schema version, regenerate the coverage documents and the model enums with the scripts in
`scripts/`.
