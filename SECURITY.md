# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in page4j, please report it privately through
[GitHub's vulnerability reporting](https://github.com/OCR4all/page4j/security/advisories/new) rather
than opening a public issue.

**Please include:**
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will get back to you as soon as possible and work with you on a fix.

## Security Updates

Security updates will be released as patch versions and announced in the CHANGELOG.
